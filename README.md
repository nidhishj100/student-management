## 💡 Problem Statement & Solution
Educational institutions often face challenges handling student records manually, leading to error-prone tracking and slow information retrieval[cite: 1]. 
This project provides a clean digital workspace mimicking **Java Linear Data Structures (`ArrayList`)** directly within a lightweight web environment to handle complete CRUD operations seamlessly.

---

## ⚙️ Core Features & Linear Data Structure Mapping
* **Dynamic Student List (`ArrayList` Simulation):** Allows sequential memory allocation and dynamic resizing when records are added or removed.
* **Indexed Searching & Traversal:** Instantly traverses records to filter by student ID.
* **CRUD Operations:**
  * **Create:** Push new student profiles into memory.
  * **Read:** Display all records sequentially.
  * **Update/Delete:** Splice and remove items dynamically using linear data manipulation.
